# Security policy

This project is pre-release and does not yet publish supported versions.

Please report vulnerabilities through GitHub's private security advisory feature for this repository. Do not open a public issue for a vulnerability that could expose device files, execute commands, corrupt packages, or compromise the Cardputer Zero system.

Zero SDR should operate without network access or a privileged background service. Hardware paths and configuration inputs must be treated as untrusted. A security report should include the affected commit, reproduction steps, impact, and any proposed mitigation.
