# Internationalization

## Supported locales

| Code | Language | Bundled font |
| --- | --- | --- |
| `en` | English | Inter |
| `zh-CN` | Simplified Chinese | Noto Sans SC subset |
| `zh-TW` | Traditional Chinese | Noto Sans TC subset |
| `es` | Spanish | Inter |
| `ja` | Japanese | Noto Sans JP subset |
| `ko` | Korean | Noto Sans KR subset |
| `fr` | French | Inter |
| `de` | German | Inter |
| `pt-BR` | Brazilian Portuguese | Inter |
| `ru` | Russian | Noto Sans subset |

Press `L` or use Settings → Language to switch. The selection is stored with the last-used radio and theme settings in the user's application configuration and restored on the next launch.

## Editing translations

All UI strings are indexed by `i18n::Text` in `src/i18n/translations.*`. Every catalog must contain a non-empty entry; `translations_test` checks completeness and locale-code uniqueness.

Keep strings short enough for 320×170. Test at least the longest Latin translation plus all four CJK locales. Abbreviations such as WFM, MHz, kHz, and dB remain technical standards rather than translated prose.

## Rebuilding font subsets

Generated subsets are committed so device and CI builds do not need system fonts. Use the four official Noto CJK variable TrueType sources from the `notofonts/noto-cjk` repository (the current assets use source commit `165c01b46ea533872e002e0785ff17e44f6d97d8`) and FontTools:

```sh
python3 scripts/build_font_subsets.py \
  --noto-jp /path/to/NotoSansJP-wght.ttf \
  --noto-kr /path/to/NotoSansKR-wght.ttf \
  --noto-sc /path/to/NotoSansSC-wght.ttf \
  --noto-tc /path/to/NotoSansTC-wght.ttf
```

The script freezes variable sources at Regular and subsets all catalog strings. Do not regenerate CJK assets from CFF-flavored Noto CJK TTC files for this app: that path triggered a reproducible FreeType crash in the LVGL desktop renderer.

After regeneration, run `python3 scripts/validate_font_assets.py` to verify that each output font contains a `glyf` table rather than `CFF`/`CFF2`, then run `ctest` and the 60-state locale screenshot smoke test documented in the README.
